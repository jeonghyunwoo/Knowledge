01 온디바이스 경량 LLM
MobileMoE: Scaling On-Device Mixture of Experts
arXiv cs.LG — 2026년 5월
핵심 내용

스마트폰·엣지 디바이스에서 MoE(Mixture of Experts) 구조 대형 모델을 효율적으로 실행하는 방법 제시. 기존 MoE는 GPU 클러스터를 전제로 설계되었으나, MobileMoE는 메모리 제약과 배터리 효율을 동시에 고려한 경량화 기법 도입.

구체적 활용방안
  • 스마트폰 앱 내 오프라인 AI 기능 내장 (인터넷 없이 동작)
  • IoT 센서·카메라 기기에서 실시간 추론
  • 클라우드 API 비용 절감 및 개인정보 로컬 처리
02 영상 생성 / 디퓨전
Image-to-Video Diffusion: From Foundations to Open Frontiers
arXiv 2605.17248 — 2026-05-17
핵심 내용

이미지→영상(I2V) 디퓨전 모델을 독립 주제로 처음 체계화한 서베이 논문. 태스크 정의·모델 아키텍처·데이터셋·평가 지표를 망라하고, 아키텍처와 학습 패러다임 기준의 분류 체계(taxonomy) 제시.

구체적 활용방안
  • 광고·스토리보드 자동 애니메이션화
  • 제품 사진 한 장 → 홍보 영상 자동 생성
  • 웹툰·일러스트를 단편 클립으로 변환하는 크리에이터 도구
03 멀티모달 추천 시스템
General Framework for Multimodal LLM-Based Recommendation
arXiv 2605.09338 — 2026년 5월
핵심 내용

텍스트·이미지·영상·오디오를 동시에 처리해 추천 품질을 높이는 대규모 시스템 설계 프레임워크. GPT-4V·Gemini 수준의 멀티모달 추론을 추천 파이프라인에 적용하는 방법론 제시.

구체적 활용방안
  • e-커머스 초개인화 추천 (상품 이미지+리뷰 텍스트+영상 동시 분석)
  • 넷플릭스·유튜브 류 스트리밍 플랫폼 다중 신호 기반 콘텐츠 추천
  • 음악 플랫폼 오디오+가사+앨범 아트 융합 추천
04 AI 코드 품질 / 기술 부채
AI-Generated Smells: Code & Architecture in LLM and Agent-Driven Development
arXiv 2605.02741 — 2026-05-04
핵심 내용

LLM·에이전트 기반 개발에서 생성된 코드의 기술 부채 패턴("AI 코드 냄새") 체계적 분류. AI는 고전적 코드 냄새와는 다른 "기계 특유의 결함 패턴"을 도입함을 실증. 프롬프트 중심 개발에서 아키텍처 복잡도 관리 중심으로의 패러다임 전환 요청.

구체적 활용방안
  • AI 코딩 도구 도입 기업의 코드 리뷰 체크리스트 재설계
  • SonarQube 등 정적 분석 도구에 AI-specific 규칙셋 추가
  • 아키텍처 복잡도 관리 중심으로 AI 개발 가이드라인 전환
05 저장소 수준 코드 생성
LLM-Assisted Repo-Level Generation with Structured Spec-Driven Engineering
arXiv 2605.02455 — 2026-05-04
핵심 내용

LLM의 코드 생성 능력은 함수 단위에서 우수하지만 저장소 전체 규모에서는 품질이 급감. 구조화된 명세(Spec) 아티팩트를 가이드로 활용하는 SSDE(Structured Spec-Driven Engineering) 패러다임 제안.

구체적 활용방안
  • 대형 소프트웨어 프로젝트 모듈 자동 생성
  • 마이크로서비스 스캐폴딩 및 보일러플레이트 자동화
  • 팀 단위 AI 협업 개발 시 명세 우선(Spec-first) 워크플로우 도입
06 LLM 에이전트 한계 분석
Constraint Decay: The Fragility of LLM Agents in Backend Code Generation
arXiv 2605.06445 — 2026-05-07
핵심 내용

백엔드 코드 생성 시 제약 조건이 누적될수록 LLM 에이전트 성능이 급격히 저하되는 "constraint decay" 현상 실증. 구조적 요구사항이 많아질수록 에이전트가 초기 제약을 잊거나 무시하는 패턴 발견.

구체적 활용방안
  • AI 에이전트 기반 백엔드 자동화 설계 시 제약 조건 분할(chunking) 전략 적용
  • 오류 내성 아키텍처: 단계별 검증 체크포인트 삽입
  • 에이전트 성능 벤치마크에 constraint accumulation 시나리오 추가
07 다중 에이전트 강화학습
Quantum Advantage in Multi-Agent Reinforcement Learning
arXiv 2605.14235 — 2026-05-14
핵심 내용

양자 얽힘(quantum entanglement)을 활용한 MARL 에이전트 조정 실험. CHSH 게임에서 얽힘 기반 QMARL 에이전트가 Tsirelson 한계(0.854)에 근접하며 고전 알고리즘의 이론적 한계(0.75)를 돌파함을 실증.

구체적 활용방안
  • 복잡한 물류·공급망 최적화 (다중 에이전트 협력 필요 시나리오)
  • 양자컴퓨팅 기반 다중 로봇 협력 시뮬레이션 연구
  • 금융 포트폴리오 다중 에이전트 최적화 탐색
08 의료 이미지 모달리티 변환
Cross Modality Image Translation In Medical Imaging Using Generative Frameworks
arXiv 2605.13686 — 2026-05-13
핵심 내용

7가지 생성 모델(Pix2Pix, CycleGAN, SRGAN, LDM, LDM+ControlNet, Brownian Bridge, Flow Matching)로 MRI↔CT 가상 변환 성능을 11개 데이터셋·3개 해부 부위·4개 변환 방향에 걸쳐 비교한 대규모 벤치마크.

구체적 활용방안
  • 추가 촬영 없이 타 모달리티 이미지 합성 → 방사선 피폭 감소
  • 희귀 모달리티 데이터 증강으로 AI 진단 모델 학습 데이터 확보
  • 저소득 의료기관에서 보유하지 않은 촬영 장비 가상 보완
09 암호화 트래픽 멀티모달 분석
Multimodal Reasoning with LLM for Encrypted Traffic Interpretation
arXiv 2604.08140 — 2026년 4월
핵심 내용

암호화된 네트워크 트래픽을 멀티모달 LLM 추론으로 해석하는 mmTraffic 시스템. 기존 딥러닝 기반 트래픽 분류를 넘어 인간이 읽을 수 있는 근거 기반 해석 리포트 자동 생성.

구체적 활용방안
  • 기업 보안 운영센터(SOC) 이상 탐지 자동화
  • 네트워크 위협 분석 → 자연어 설명 리포트 자동 생성
  • 보안 담당자 교육용 트래픽 패턴 시각화 도구
10 GraphRAG 적용 기준 분석
When to Use Graphs in RAG: A Comprehensive Analysis for GraphRAG
arXiv 2506.05690
핵심 내용

GraphRAG(그래프 구조 기반 RAG)가 일반 벡터 RAG 대비 효과적인 조건을 체계적으로 분석한 종합 연구. 엔티티 관계·계층적 의존성이 중요한 도메인에서 그래프가 유리함을 실증하고 적용 기준 프레임워크 제시.

구체적 활용방안
  • 기업 내 지식 관리 시스템: 부서 간 관계·프로세스 연결이 많은 문서에 GraphRAG 적용
  • 의료·법률 분야 다단계 추론 Q&A 시스템 구축
  • 단순 문서 검색은 벡터 RAG, 복합 관계 추론은 GraphRAG 분기 설계
주요 흐름 요약

경량화 & 온디바이스

클라우드 없이 스마트폰·엣지에서 실행 가능한 모델로 급속 이동. MoE 아키텍처의 모바일 적용이 핵심 과제로 부상.

코드 에이전트 현실 점검

AI 코드 생성의 품질 문제·한계를 실증적으로 파헤치는 논문 급증. "생성"에서 "아키텍처 관리"로 관심 이동.

멀티모달 실용화

추천·보안·의료 등 버티컬 도메인에 멀티모달 추론 적용 본격화. 연구 단계를 벗어나 시스템 설계 논문 증가.

GraphRAG 성숙

"언제 그래프를 써야 하나"를 논의할 만큼 GraphRAG가 실용 단계 진입. 적용 기준 프레임워크 정립 시도.
