# Knowledge

AI · 데이터 분석 분야의 리서치 산출물을 모아두는 공개 저장소입니다.

논문 리뷰, 트렌드 분석, 실험 노트, 시각화 결과물 등을 HTML 리포트 형태로 정리해 GitHub Pages를 통해 바로 열람할 수 있도록 게시합니다.

---

## 수록 기준

- **AI / ML** — LLM, 멀티모달, 에이전트, 강화학습, 생성 모델 등 최신 arXiv 논문 요약 및 실용 활용방안 분석
- **데이터 분석** — 탐색적 분석(EDA), 시각화, 인사이트 도출 과정 기록
- **도구 · 워크플로우** — Claude Code, Obsidian, 자동화 스크립트 등 실제 작업 환경 메모

산출물은 단순 정보 수집이 아닌 **"이걸로 뭘 할 수 있는가"** 를 중심으로 작성합니다.
